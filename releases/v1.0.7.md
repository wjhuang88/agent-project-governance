## Summary

- Added an evidence and uncertainty contract so Agents distinguish confirmed facts, inferences,
  assumptions and unknowns before making closure claims.
- Tightened release publishing so every release includes Agent-authored release notes plus an
  automatically appended commit list and installation instructions.
- Updated skill metadata to follow the Agent Skills specification by placing author and version
  under `metadata`.

## Notable Changes

- Governance closure now asks Agents to classify important claims by evidence strength and avoid
  reporting high-impact assumptions as complete facts.
- `SKILL.md` now links the evidence/uncertainty and evolution-feedback references from its
  resource list, improving load-path discoverability.
- README release-channel documentation now matches the current zip, tar.gz and tar.zst archive
  publishing behavior.

## Upgrade Notes

- Release automation now requires `releases/<tag>.md` before a `v*` tag is pushed.
- Skill metadata version is now `1.0.7`.
