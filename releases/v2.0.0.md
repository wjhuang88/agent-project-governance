## Summary

- Introduced evidence-based project scale assessment for governance profile, branch mode and
  worktree mode decisions.
- Added limited Git branch/worktree guidance so projects can adopt release and hotfix isolation
  without defaulting to full GitFlow.
- Added shell and PowerShell scale-assessment harness templates for generated user projects.

## Notable Changes

- New `project-scale-harness` reference defines mechanical signals, thresholds, trigger scenes and
  output contract for profile and mode recommendations.
- New `git-branch-and-worktree` reference defines `simple`, `release-managed` and
  `parallel-agent` modes, with explicit guidance to avoid `develop` unless justified.
- Harness design now treats scale, branch and worktree recommendations as executable checks where
  possible.

## Upgrade Notes

- Skill metadata version is now `2.0.0`.
- Existing projects do not need to adopt release branches or worktrees automatically. Run scale
  assessment first, then update local governance only when observed signals justify it.
